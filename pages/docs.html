Documentation

Everything you need to get started with ReportDrafter — from first upload to final download.

Getting Started

1. Create Your Workspace

Sign up at reportdrafter.com and create a workspace. Available workspace and team features depend on the current product configuration.

2. Upload a Report Template

Navigate to Templates → Upload and select your report template file. Supported formats:

  • .docx — Word documents with placeholder fields, merge fields, or labeled cells
  • .xlsx — Excel workbooks with named ranges, headers, or labeled cells

ReportDrafter analyses supported template structures to identify the fields used for extraction. Review the generated field list before relying on it.

3. Add Source Documents

Upload one or more source documents that contain the data to be extracted. Supported formats include .pdf, .docx, and .xlsx. The platform can process structured tables, narrative text, and mixed-format documents.

4. Run AI Extraction

Click Extract to start the AI extraction job. The model reads your source documents, maps content to template fields, and returns candidate values with a confidence score for each field.

Processing time varies with document size, file type, model availability, and the number of requested fields.

5. Review & Edit Fields

Fields are displayed in a table view, sorted by confidence (lowest first by default). For each field you can:

  • Accept — keep the AI-extracted value
  • Edit — manually correct the value
  • Review — compare the candidate value with the available evidence
  • Re-run — where enabled, request another extraction for an individual field

6. Download Your Report

Once you have reviewed the fields, generate the report. ReportDrafter applies the selected values to the template and produces a downloadable .docx or .xlsx file. Always inspect the output before using or distributing it.

Understanding Confidence Scores

Every extracted field includes a confidence score from 0% to 100%:

Confidence score ranges and guidance
Score RangeColorGuidance
90–100%🟢 GreenHigher confidence — still verify against the source before approval
70–89%🟡 AmberMedium confidence — review recommended, may need minor correction
0–69%🔴 RedLow confidence — manual review and correction likely needed

Confidence scores are influenced by factors like source document clarity, field specificity, and the amount of matching context available. You can view score history across extraction runs in the field detail panel.

Template Best Practices

  • Use clear, descriptive field labels (e.g., "Fund Name" instead of "Field 1")
  • Keep template structure consistent — avoid mixing manual text with placeholder fields in the same cell
  • For Excel templates, use named ranges or header rows for best detection
  • Avoid heavily styled or image-based templates — the parser works best with text-based layouts

Workspace Settings

Team Management

Where team features are enabled for your workspace, use Settings to manage available members and access controls. Confirm the current role model in the product before relying on it for a segregation-of-duties requirement.

API Keys

Generate API keys from Settings → API for programmatic access. See the API Reference for endpoint documentation.

Data Retention

Data-retention options depend on the deployment and workspace configuration. Contact support before relying on a particular retention or deletion schedule.

Supported Languages

The ReportDrafter interface is available in 24 languages: English, Spanish, French, German, Italian, Portuguese, Dutch, Swedish, Norwegian, Danish, Finnish, Japanese, Chinese (Simplified), Chinese (Traditional), Arabic, Turkish, Korean, Thai, Vietnamese, Polish, Czech, Romanian, Hungarian, and Greek.

The AI extraction engine processes source documents in any language, though confidence scores may be higher for documents in widely-used languages with more training data.

Troubleshooting

Extraction returns low confidence on all fields

This usually means the source document format isn't matching well with the template structure. Try using clearer field labels in your template, or ensure the source document contains the expected data in a parseable format (not scanned images).

Upload fails for large files

The browser client currently accepts files up to 49 MB each. For larger files, consider splitting them into sections. If uploads fail, check the file type, total package size, and network connection.

Exported report has missing formatting

Complex formatting (conditional formatting, macros, VBA) may not be preserved in all cases. Stick to standard cell formatting, fonts, and merged cells for best results.
